## Folder convention

Each future batch should be stored in a new `YYYY-MM-DD` folder so earlier versions remain easy to find and share.

Each dated folder contains:

- `index.html` — the searchable and filterable offline gallery
- `assets/` — the original full-resolution PNG ads, grouped by audience
- `README.txt` — instructions for viewing and sharing the gallery

To use the gallery, download the dated folder (or the repository), then open its `index.html` file in a web browser.
